# Project-Local Installation

Project-local skill installation is the preferred model for migration work because the slash-command bundles travel with the consumer repository.

The operator entry point is documented in [Migration Harness Operator Guide](../04-operator-guides/instruction.md). Tool-level installation behavior is documented in [MCP Tools, Skills, and Prompts](../03-mcp-and-agent-harness/mcp-tools-skills-prompts.md).
